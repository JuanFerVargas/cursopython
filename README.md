instalar JupyterLab desde la consola de Python, normalmente se utiliza el gestor de paquetes pip. Aquí tienes los pasos:

✅ 1. Verifica que pip esté actualizado
    python -m pip install --upgrade pip

✅ 2. Instala JupyterLab
Ejecuta:
    pip install jupyterlab

Esto descargará e instalará la última versión estable de JupyterLab.

✅ 3. Comprueba la instalación
Una vez instalado, puedes verificar la versión con:
    jupyter-lab --version

✅ 4. Ejecuta JupyterLab
Para abrirlo, simplemente escribe:
    jupyter-lab

Esto abrirá la interfaz en tu navegador por defecto.
